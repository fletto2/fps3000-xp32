# AMD Am29500 DSP reference design — AMDASM source (DSP.DEF + FFT microcode)

Extracted verbatim from `refs/datasheets/AMD_Am29500_Family_Handbook_1986.pdf`,
Appendix 2, via `pdftotext -layout`. Lines 8139-9695 of that extraction.

## Why this is here

This is the microcode definition file and worked FFT source for AMD's
reference DSP board — the design the FPS-3000 XP32 ARITH card matches
part for part (see `notes/xp32_arith_is_amd_reference_fft.md`). It is
the closest thing to XP-32 AU microcode that exists outside a real
XPMLIB kernel, and it is a **128-bit horizontal microword** like the
XP-32's.

It contains:

- `WORD 128` and the bit-numbered field map, four 32-bit quarters:
  Real ALU (127-96), Imaginary ALU (95-64), Multiplier + Address
  Generator (63-32), Program Sequence (31-0)
- an explicit **`ADDRESS GENERATOR OVERLAY`** section in which the same
  bits carry a 16-bit Am29116 instruction (`I15…I00`) instead of Am29540
  FFT control
- `EQU` definitions for the Am29501 ALU functions, port selects and
  multiplier controls
- worked microcode for **forward FFT, inverse FFT, the butterfly loops
  (`BTF.LOOP`, `IBTF.LUP`) and matrix multiply (`MXMULT`)**

Each microinstruction is written as a lead line plus `/&` continuation
lines, one per resource group — the horizontal-microcode idiom, and a
direct illustration of how the four quarters are filled in parallel.

## Read with care — this is OCR

The source PDF has a text layer of mediocre quality. Known systematic
damage:

| Appears as | Almost certainly |
|---|---|
| `H 110`, `Hfl 4`, `H/18`, `HllD` | `H#0`, `H#4`, `H#8`, `H#D` (AMDASM hex) |
| `Q 110`, `Qfl1`, `Q/14` | `Q#0`, `Q#1`, `Q#4` (AMDASM octal) |
| `I&`, `/&` | `&` (continuation marker) |
| `8` in register names (`83`, `82`, `81`) | `B3`, `B2`, `B1` |
| `2VB/111`, `2VB#11` | `2VB#11` |
| `~`, `1t`, `tt` in rule lines | decorative separators |

**Do not treat any single token here as authoritative.** Use it for
structure — field groupings, which resources are controlled together,
how a butterfly is scheduled across parallel units — and go back to the
PDF page for any specific bit value that matters.
