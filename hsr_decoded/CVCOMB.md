# CVCOMB — AP-120B microcode

- Library: **BAALIB**
- Args (NSPADS): **7**
- Entry uPC: **000** (octal)
- Microcode size: **10** instructions (80 bytes)

## Host-side PDP-11 stub

```

        .GLOBL CVCOMB,APEX
CVCOMB: MOV (%5)+,%0
        BEQ NONE
        MOV #SLIST,%1
LOOP:   MOV @(%5)+,(%1)+
        DEC %0
        BNE LOOP
NONE:   MOV #PARAM,%5
        JSR %7,APEX
        RTS %7
PARAM:  4
        CODE
        START
        SLIST
        NSPADS
NSPADS:      7.
SLIST:  .BLKW      7.
START:       0.
CODE:       10.
```
