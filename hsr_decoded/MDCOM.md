- Library: **BABLIB**
- Args (NSPADS): **2**
- Entry uPC: **000** (octal)
- Microcode size: **11** instructions (88 bytes)

## Host-side PDP-11 stub

```

        .GLOBL MDCOM ,APEX
MDCOM : MOV (%5)+,%0
        BEQ NONE
        MOV #SLIST,%1
LOOP:   MOV @(%5)+,(%1)+
        DEC %0
        BNE LOOP
NONE:   MOV #PARAM,%5
        JSR %7,APEX
        RTS %7
PARAM:  4
        CODE
        START
        SLIST
        NSPADS
NSPADS:      2.
SLIST:  .BLKW      2.
START:       0.
CODE:       11.
```
